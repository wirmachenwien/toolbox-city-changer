# Component Showcase

This page is your Markdown reference. Markdown is the simple formatting language used to write all handbook chapters.

## Markdown basics

New to Markdown? Start with the [basic syntax overview on Markdown Guide](https://www.markdownguide.org/basic-syntax/) — it covers everything below in a few minutes.

Use `#` for headings. The more `#` characters, the lower the heading level. Use only one top-level heading (`#`) per page — that's the page title.

## Subheading
### Smaller subheading

You can format text with **bold**, *italic*, ~~strikethrough~~, and [links](https://example.com).

Unordered list:

- Bullet point
- Another point

Ordered list:

1. First step
2. Second step
